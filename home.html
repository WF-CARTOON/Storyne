اختبار showSaveFilePicker

تفتح نافذة النظام ليختار المستخدم مكان حفظ الملف واسمه. …

1) حفظ نص

اكتب أي نص ثم اضغط حفظ. اختر المكان في نافذة النظام.

2) حفظ JSON

يحفظ كائنًا مُنسّقًا كملف .json.

3) حفظ صورة (Blob ثنائي)

يرسم صورة PNG على canvas ثم يحفظها.


4) ملف كبير

يولّد ملفًا بحجم تختاره (ميجابايت) ويحفظه على دفعات، لاختبار الملفات الكبيرة.

MB

5) القراءة بعد الحفظ (getFile)

يكتب نصًا ثم يستدعي handle.getFile() ويعرض ما كُتب. القراءة من ذاكرة الصفحة الحالية فقط.

6) إلغاء المستخدم

اضغط ثم أغلق النافذة بدون اختيار: يجب أن يصلك الخطأ AbortError ولا يحدث شيء آخر.

7) إعادة التشغيل (onCreate)

أي عنصر عليه onCreate="reload.rostrick.page" يعيد تشغيل التطبيق عند الضغط عليه.

طريقة الاستخدام في صفحتك

  
// 1) افتح نافذة اختيار المكان
const handle = await window.showSaveFilePicker({
  suggestedName: "report.txt",
  types: [{ description: "Text", accept: { "text/plain": [".txt"] } }]
});

// 2) اكتب المحتوى
const w = await handle.createWritable();
await w.write("hello");            // نص أو Blob أو ArrayBuffer
await w.write(new Blob([bytes]));  // يمكن الكتابة عدة مرات
await w.close();                   // الحفظ الفعلي يحدث هنا

// 3) (اختياري) اقرأ ما كتبته للتو
const file = await handle.getFile();
console.log(file.name, file.size, await file.text());

  
ملاحظات مهمة
    
- لازم تُستدعى من ضغطة مستخدم (زر/رابط)، وإلا قد يرفضها النظام.
- الحفظ يتم عند w.close(). قبلها لا يُكتب شيء.
- إلغاء المستخدم يرمي AbortError: التقطه بـ try/catch.
- getFile() يرجع آخر ما كُتب في نفس الجلسة (ذاكرة الصفحة)، ولا يقرأ ملفًا قديمًا من الجهاز.
- نوع الملف (MIME) يؤخذ من أول أنواع accept في types.
- الملفات الكبيرة تُرسل على دفعات تلقائيًا.
